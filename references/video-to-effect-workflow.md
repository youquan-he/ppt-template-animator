# 从参考视频到可复用的 PPT 效果

适用于用户给出一段 PPT 演示视频、示范 PPTX，或要求把一次调试成功的效果作为“效果 x”供后续调用。视频是动态参考，PPTX 是可编辑结构和参数的证据；两者信息不足时，标出未知项，不声称精确复刻。

## 学习与制作

1. **拆成状态与动作**：记下画幅、初始画面、每次点击或自动触发、对象的出现/退出/位移/缩放/旋转、遮挡与层级、页间转场、终态及观众需要阅读的停留。对视频抽取有变化的关键帧；不要只看封面或最终一帧。
2. **有模板就读源对象**：记录连续源页范围，检查切换、背景、图片裁切与格式、形状和文本框的位置/大小/样式、组合层级、画布外对象、时间轴与触发关系。把模板文字、数据和图片当作可替换示例；只将可编辑结构及适合目标内容的动作迁移到新稿。
3. **先做真实内容的样例**：用本次素材搭建核心场景，按参考顺序完成原生对象动画或连续 Morph。只有视频而无 PPTX 时，用画面提出可检验的实现假设；在样例中试播、修正，并记录与参考仍有差异的地方。
4. **反馈后登记“效果 x”**：调试记录使用稳定代号和描述性名称，并写明来源链接、源文件与页范围、适用场景、所需素材、对象结构、状态/触发/时长、可替换内容、复现步骤、依赖及已验证的 PPTX。把用户的具体修改反馈更新到配方，不把一次未经检查的初稿写成已完成效果。保存位置和是否需要额外确认遵守本次任务要求；不沿用视频作者的个人桌面路径或口令。
5. **调用时重新适配**：收到“使用效果 x”后，先读取该配方及已验证样例，把新素材映射到相应对象，并重新计算文字长度、裁切、运动距离和停留时间。效果代号是检索入口，不保证换素材后自动保持可读或动作正确。

## 两个容易破坏动画的改写点

- **组合内文本**：递归检查组内文本框与占位文字。改字或改背景后检查对象、组合、动画目标和触发是否仍然绑定，避免只替换组外的可见文字。
- **跨页连续对象**：Morph 中画布内外的文本框、遮罩和支点可能是同一对象的不同状态。保留相邻页与稳定身份，按对象关系匹配后再改位置或内容；不要因为对象越过画布边界就当作两件独立素材重新创建。实播检查是否跳变、闪白或丢字。

复杂多对象动作先在代表场景核实 PowerPoint 原生实现和可编辑性。HTML 可以作为另行约定的交付形式或辅助预览，但用户要 PPTX 时，不能悄悄用 HTML 动画替代。交付前在原生 PowerPoint 打开并播放最终文件，核对组内文字、背景、裁切、对象身份、触发顺序和转场连续性；静态预览和“有动画 XML”都不能代替实播。
