# 设计与复核方法

用于本 Skill 的需求判断、原创设计、模板重组与润色。以下方法已整合为可执行规则，无需每次加载全部源 Skill。源工具和外部服务只有在当前任务确实需要且可用时才采用。

## 先确定交付方式与修改范围

| 场景 | 对设计的影响 |
| --- | --- |
| 现场讲述 | 一页一个主要任务；正文低密度；解释和来源进入备注；点击跟随讲述；重点检查初始状态与揭示顺序 |
| 独立阅读 | 关键定义、论据与结论在页面可见；不依赖讲者或某次点击才能理解；复杂图可以加简短说明 |
| 两者兼顾 | 保持可读的最终状态，备注承载演讲细节；需要独立阅读副本时单独输出静态版并说明，不能覆盖动态原稿 |
| 严格沿用模板 | 保留指定模板的母版—版式—页面层级和视觉规范；内容不合适时换页型/拆页，不偷改字号或另盖一套设计 |
| 提取参考、重新创作 | 复用组件和方法，围绕主题重建层级与构图；保留一致的字体、语义颜色、间距和动作逻辑 |
| 仅排版润色 | 先记录文字、数值、引用、备注、页序；仅做授权的视觉变更，之后逐项比对，避免润色导致内容漂移 |

用户最新明确指示决定场景。不要仅因为收到 PPTX 就锁死“必须逐页照搬”，也不要因本 Skill 支持拆解而擅自重做严格保真的任务。

## 叙事与分镜

用一句话定义观众结果：结束后，哪些观众应理解、判断或采取什么行动，以及哪些证据支持它。中立教学或参考稿可以围绕一个问题组织，不强行变成推销或建议书。

每页分镜至少含：页序、叙事任务、主张/问题型标题、素材 ID、关键图像、构图、初始可见状态、点击步骤、阅读停留、预计讲述时长、与下一页的连接。时长用于预算，不是播放软件自动确认的真实演讲时长。重用同一图进行总览—细节时保留方向和颜色语义；不因“不能重复用图”而打断合理解释。

每张关键图回答“这说明什么、为何与当前问题有关”。图表和数据不能成为孤立的库存清单。段落之间有因果、问题—回答、流程或时间关系；结束页回应开头，可以保留有用途的致谢/问答，但不能用空泛口号代替结论。

教学页按需检查动机是否先于定义、术语和符号是否逐步引入、新概念是否有例子、需要直接比较的内容是否能同屏看到。商务、参考或技术报告不强制套用课堂叙事。

## 全稿设计规格

在工作文件记录可复用规格，不为每页单独发明风格：

- 主题气质与视觉方向：克制、活泼、实验观察、技术解释等，需由观众和内容支持。
- 背景、主色、辅助色、强调色及其语义；同一颜色在不同页不随意改含义。区分类别时也使用文字、形状或线型。
- 中文、西文、数字的真实可用字体和替代方案；封面、标题、正文、图注、来源的层级。先以实际显示字号验证，而非把某个英文模板的绝对字号强加给所有中文页面。
- 页边距、对齐、留白、文字框内边距、图像边框/阴影/裁切、图注位置。可以有数种页型，但沿用这些共同规范。
- 动作规范：标题、证据、标注、流程、跨页连接各自何时使用动画，什么时候保持静止。

`decompose_template.py inspect` 从实际关联的母版主题读取配色、主/次字体和脚本字体，并报告对象声明的字体、字号、RGB 与主题颜色引用。它不会自动解析全部继承、颜色变换和字体替换；未声明不等于没有字体，`+mn-ea` 等也不是可直接安装的字体名。最终以原生渲染检查为准。

先验证代表性困难页面：例如最大证据图、最密中文说明或最长动画链；必要时另验封面风格。确认视觉与技术路线可行再扩展，不为每种场景机械要求相同数量的试做页。

选择页型前数清实际内容：两项对比不为三栏模板虚构第三项，引语版式须有真实可引用的话，图像框须有与论点相关的图。模板的页型标签只是候选，必须看图确认；使用说明页只能在确认该模板的结构后跳过，不能对所有模板固定跳过前六页。

## 中文、图文与数据

- 检查中文缺字和替代字体、中英混排基线、中文标点、数字与单位、专业缩写、图注和表格内文字。不要人为在汉字之间加空格；不要机械应用固定行距倍数或全稿字号倍增。
- 计划为单行的标题不要意外折行；有意采用两行标题时，在设计规格中明确并验证。先改写、调整构图或均衡拆页，避免一页拥挤、下一页空泛。
- 证据图应足以辨识关键细节，标签靠近被解释对象；示意图与真实证据清楚区分。不能把图片、表格或图表变成不可读的小装饰。
- 简单关系图优先可编辑原生对象；复杂示意选择合适工具并核对事实。连接线与箭头层级不遮住节点/标签，连接含义全稿一致。不要将所有页面排成类似界面的卡片网格。
- 数据关系能用图表表达时选择合适图型，核对数据、单位、分母、图例、坐标范围、误差与来源；可编辑图表保留数据。宽表可按问题分组或拆页，不能删掉重要列来迁就框架。
- 外部素材和非平凡事实在对应页备注保留来源记录，例如 `[Sources]`；需要观众看见的来源在页面注明。覆盖台账仍需指向内容本身，不能用引用代替应用。

## 分线复核和定点修复

| 复核线 | 重点 |
| --- | --- |
| 视觉 | 全尺寸逐页检查文字、裁切、重叠、清晰度、对比、连接线和空白；缩略图检查整稿一致性与变化 |
| 叙事/理解 | 主线能否串起来；证据是否解释结论；观众前置知识是否足够；密度与节奏是否合适；重复是否有目的 |
| 文字/事实 | 材料覆盖、数字单位、图表与原数据、术语、引用、样例占位、承诺与来源是否一致 |
| 动态/文件 | 初始状态、点击顺序、同步关系、停留、Morph/路径依赖、原生保存后效果和可编辑对象是否完整 |

每条问题记录：最终页码、对象 ID/名称或明确位置、问题、严重度、修复、复核结果。阻断问题包括必用材料遗漏、事实/数据错误、关键内容不可读、文件打不开和必要动画/编辑能力丢失，必须清零。审美改进单独列出，不能以一个总分掩盖阻断项。

发现问题后只改受影响的内容，重新渲染相关页与前后动画衔接；修改全局主题/母版时扩大到其影响页。长稿或高风险内容可由独立审阅者分别检查这些维度，再合并同一对象的问题；不强制调用固定外部模型或上传私有素材。
